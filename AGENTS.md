# HashBrown contributor instructions

This is the independent `hashbrown-ir` distribution, `hashbrown_ir` Python package,
and `hashbrown` CLI. Own code, artifacts, case store, tests and documentation live
here. Do not import sibling projects, create a shared installer/engine or introduce
automatic cross-tool case linkage. Keep the package usable in an isolated venv.

Read `agents/acquisition.md` before changing acquisition or evidence handling.
Preserve third-party notices for adapted MIT code. Use Python 3.12+ and the standard
library unless a dependency is necessary and explained.

Run `python -m unittest discover -s tests -v` and the inert `hashbrown --root TEMP demo`
after relevant changes. Tests must never read a physical disk/RAM, load a driver,
modify security policy, provision a server or submit remote collections. Native
capture requires an explicitly designated, authorized VM and is a separate acceptance
step. Do not describe API doubles or generated bytes as live capture validation.

For Windows verbose command output, prefer installed RTK test/build/git wrappers
when they preserve runner, arguments and exit status. Use PowerShell cmdlets
normally. Use targeted `rg` and full relevant source/diffs for precise review.

Maintain the public command contract in README and docs with implemented behavior.
Do not publish, push, create releases or submit remote jobs without authorization.
